# SkyBag Fee Calculator (ICT602 Mobile Technology Assignment)

Android app (Java) that estimates excess baggage fees.

- Inputs: baggage weight (kg), ticket class (Economy 20 kg / Business 40 kg), rate per kg (RM)
- Outputs: excess weight, excess charge, total payable (charge + 8% service tax)
- Share button in the action bar, About page with clickable URL
